# Rathod Ramraj — Portfolio

Personal portfolio for Rathod Ramraj. Vite + React + TypeScript SPA, deployed on Vercel at [rathodram.vercel.app](https://rathodram.vercel.app).

### Stack

- Vite 6, React 18, TypeScript
- `wouter` for client-side routing (`/`, `/projects`)
- LeetCode stats API integration
- GitHub REST API via a server-side proxy

## Run

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start Vite dev server with proxy
- `npm run build` — production build
- `npm run serve` — preview the built bundle
- `npm run typecheck` — `tsc --noEmit`
